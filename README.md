# NextPlay Android — Version 1.0 (source project)

A native Android application wrapping the existing NextPlay AMOLED UI and adding a persistent local media library. **This ZIP contains Android source code, not a compiled APK.** GitHub Actions builds the debug APK.

## Features implemented

- Preserves the original NextPlay dark/AMOLED homepage, tabs, local media tools, browser shortcuts, link cleaner, and local playback.
- Android file-picker integration for the web preview's audio/video inputs.
- **Native saved media library:** Android Storage Access Framework picker, saved `content://` URIs and long-lived read permissions, native in-app video/audio playback; items remain listed after app restarts. Files are not copied or uploaded.
- Native video playback using `VideoView`, MediaController, play/pause, 10-second seeks, optional playback speeds, and brightness/volume swipes.
- Native audio playback, play/pause, seek, playback speed, progress bar.
- Authorized **direct HTTPS media-file download** using Android DownloadManager; only common audio/video extensions are accepted. Download is queued, and the resulting file can be added to the library after completion. This does NOT fetch YouTube streams.
- Open sites and videos in the system browser/official app when invoked by the web UI.
- Third-party SponsorBlock segment metadata / Return YouTube Dislike community estimate lookups in the existing UI, **best effort**, no automatic skipping or modification to the YouTube player.
- Remembers website UI theme, incognito choice, and app search history (except searches done while incognito is enabled).

## Explicit limitations

| Feature | Status |
| --- | --- |
| YouTube ad blocking | **Not implemented**; YouTube API policies disallow altering/removing player ads. |
| YouTube stream download / audio extraction | **Not implemented**. |
| SponsorBlock automatic YouTube skip | **Not implemented**; metadata lookup only. |
| Community dislikes | Best effort, third-party estimates; not official YouTube counts. |
| Hide Shorts | Hides shortcuts in NextPlay UI only, not YouTube's UI. |
| Force YouTube video quality | **Not implemented**. Native file quality is determined by the file. |
| Browser site ad filtering | **Not implemented**. |
| Native offline media library | Implemented via saved Android file URI permissions. File must remain accessible at its original location. |
| Authorized media direct downloads | Queued with Android DownloadManager; target server must supply a directly downloadable HTTPS media file. |
| Android APK file | Generated by GitHub Actions after uploading/pushing this source. Not compiled in this environment. |

## Build on GitHub from your Android phone (Codespaces path)

1. Download `NextPlay_Android_Source.zip` and keep it in your phone's Downloads folder.
2. In Chrome on Android, sign into [github.com](https://github.com), create a **new repository** named `NextPlay-Android` (choose Private if you like), and create it with a README so a `main` branch exists.
3. In the repo select **Code → Codespaces → Create codespace on main**. On mobile, turning on Chrome's **Desktop site** may make the editor easier to use. Codespaces availability and usage limits depend on your GitHub plan.
4. In the Codespaces browser editor, use **Explorer → Upload** to upload `NextPlay_Android_Source.zip` to the repository root.
5. Open the Codespaces **Terminal**. Run:

   ```bash
   unzip -o NextPlay_Android_Source.zip
   git add .
   git commit -m "Add NextPlay Android app"
   git push origin main
   ```

   The archive extracts project files at the repository root. **Do not commit any OpenAI API keys** (none are needed for this app).

6. Open your repository's **Actions** tab → select **Build NextPlay APK**. The push should trigger the workflow automatically; otherwise choose **Run workflow**. Some new repositories require GitHub Actions to be enabled first.
7. When the workflow completes successfully, open that run → **Artifacts** → `NextPlay-debug-APK`. Download and unzip the artifact. Inside is `app-debug.apk`.
8. On your Android phone, open that APK and allow installation from your chosen file manager/browser when prompted. Only install APKs built from source you trust.

### Alternative: Android Termux (if Codespaces is unavailable)

Use Termux from an official source, install `git` and `unzip`, then clone your repo, copy/extract the ZIP from phone storage, and push the project using your GitHub authentication method. GitHub Actions can build the APK; you do **not** need an Android compiler on the phone itself.

## Technical build configuration

- Language: Java, no Kotlin/AndroidX dependencies.
- Android API: min 24; target 35; compile 36.
- Android Gradle Plugin 9.4.0 + Gradle 9.6.0 + JDK 17.
- Only app permission declared: `INTERNET`. Local files are accessed using the Android system file picker and read-grant permissions.
- Package name: `com.nextplay.app`.
- Debug APK is for personal testing; distribution on Play Store requires additional testing, release signing, Play policies, and review.

## Suggested manual checks after APK build

1. Start the app. Switch tabs and theme, close/relaunch, verify settings persist.
2. Open Library → **Open saved Android library** → add a locally stored audio/video file.
3. Play file, test play/pause and seeking; try speed and gestures. Restart app, verify file remains listed and playable.
4. Check clean-link UI removes known tracking parameters. Search/browser buttons open external browser.
5. Add a direct `.mp3` or `.mp4` URL you are authorized to download and verify system Downloads after completion.
6. For YouTube, verify normal official playback/link opening. Do not assume any ad blocking or downloads.
7. Confirm there are no crashes on your specific phone/Android release.

## Security and legal scope

This project doesn't use any OpenAI API key or contact OpenAI. The web UI contacts third-party websites only when you open them or request community metadata; those services can have their own privacy policies. Source has not been compiled or device-tested here. YouTube's documented API policies restrict ad modification and audiovisual downloading; do not reimplement those using undocumented APIs.
